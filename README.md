# Zotero Drop Callout

Automatically format PDF highlights dragged from **Zotero** into **Obsidian** as page-aware Markdown callouts.

This small desktop-only Obsidian plugin works with Zotero's native PDF reader and preserves deep links to individual annotations. It lets Obsidian handle the native drop first, then rewrites only the inserted text when a Zotero PDF link is detected.

## Example

**Input** (representative Zotero drag output):

```markdown
> [!quote] PDF Highlight
>
> In RBO, we test the optimization performance... ([pdf](zotero://open-pdf/library/items/HGACVREL?page=3&annotation=L5RV6EX5))
>
> 📄 Open PDF · (Tom 等, 2025, p. 3)
```

**Output**:

```markdown
> [!quote] PDF Highlight · Page 3
>
> In RBO, we test the optimization performance...
>
> [📄 Open PDF](zotero://open-pdf/library/items/HGACVREL?page=3&annotation=L5RV6EX5) · (Tom 等, 2025, p. 3)
```

## Features

- Automatically reformats eligible Zotero PDF highlight drops; no hotkey required.
- Extracts `page` from the `zotero://open-pdf/` deep link.
- Moves the PDF link into the callout footer and labels it **Open PDF**.
- Removes duplicate Open PDF footer labels generated by existing Zotero note templates.
- Preserves citation text and existing Markdown citation links where present.
- Leaves ordinary drag-and-drop content unchanged.
- Does not modify previously existing notes or annotations.

## Installation

1. Download the source archive or clone this repository.
2. Copy `main.js` and `manifest.json` into `<your-vault>/.obsidian/plugins/zotero-drop-callout/`.
3. Restart Obsidian, or reload community plugins.
4. Enable **Zotero Drop Callout** under **Settings → Community plugins**.
5. Drag a PDF highlight from Zotero's PDF reader into an editable Obsidian note.

Obsidian **1.5.0+** is declared in the manifest. The plugin is desktop-only. It has been manually verified in one user's Zotero 10 / Obsidian workflow; broader compatibility is not yet established.

## Zotero template

The following Zotero native highlight note template is one tested starting point (Zotero advanced preference `extensions.zotero.annotations.noteTemplates.highlight`):

```html
<blockquote>
  <p>[!quote] PDF Highlight</p>
  <p>{{highlight quotes='false'}}</p>
  {{if comment}}
  <p><strong>Note:</strong> {{comment}}</p>
  {{endif}}
  <p>📄 Open PDF · {{citation}}</p>
</blockquote>
```

Zotero's citation formatting follows its own settings; this plugin does not translate citation styles or author names.

## How it works

The plugin listens for Obsidian `editor-drop` events and checks whether the dropped text/HTML contains a `zotero://open-pdf/` link. It lets the editor perform the original drop to preserve native rich-text conversion, then compares the editor contents before and after insertion. If the inserted segment contains a supported PDF link, it replaces that segment with a Markdown callout.

Only the first PDF annotation link in a dropped segment is used. Batch drags containing multiple annotations, unexpected Zotero HTML variants, and drops outside editable Markdown views may require future improvements.

## Development and tests

The plugin currently ships as plain JavaScript with no build step or runtime dependencies beyond Obsidian's plugin API.

```bash
npm test
```

Tests exercise the formatter against representative Zotero Markdown drops. CI runs `node --check` and `npm test`.

## Privacy

The plugin processes drop data locally inside Obsidian. It contains no telemetry, network requests, or external services.

## Limitations

- The PDF URL parser expects Zotero's `zotero://open-pdf/` scheme and a Markdown `[pdf](...)` link in the inserted content.
- It does not automatically reformat historical notes.
- Citation formatting is controlled by Zotero.
- Automated tests do not replace interactive testing with Zotero and Obsidian.
